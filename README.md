# Laboratorio de estadística aplicada

Aplicación web educativa para estudiar la relación entre el **uso académico de herramientas de inteligencia artificial** y el **rendimiento académico**. Presenta un estudio de caso interactivo con datos sintéticos de estudiantes, diseñado para practicar el análisis estadístico y la interpretación crítica de resultados.

## ¿Qué permite explorar?

- Un cuestionario de 12 preguntas sobre hábitos de uso de IA, verificación de respuestas, tiempo de estudio y promedio académico.
- Una base de datos simulada que se puede buscar, filtrar, ordenar, regenerar y descargar en CSV.
- Distribuciones de frecuencia para el uso principal de IA y las horas semanales dedicadas a estas herramientas.
- Medidas descriptivas, como media, mediana, moda, desviación estándar, cuartiles y percentiles.
- Una tabla de contingencia y una prueba chi-cuadrado para explorar la asociación entre verificar respuestas de IA y alcanzar un promedio alto.
- Correlación de Pearson y regresión lineal simple para analizar la relación entre horas de uso de IA y promedio académico.
- Gráficos de barras, histograma, polígono de frecuencias, gráfico circular y diagrama de dispersión con recta de regresión.

Cada análisis incluye una explicación de cómo interpretar sus resultados. Al filtrar o generar una nueva muestra, las tablas, los cálculos, los gráficos y las conclusiones se actualizan con los registros visibles.

## Alcance del estudio

**Todos los datos son sintéticos y tienen fines educativos.** No representan estudiantes reales ni permiten afirmar que usar IA mejore o empeore el rendimiento. Las relaciones observadas pueden depender de otros factores, como las horas de estudio, el semestre o la carga académica. El objetivo del laboratorio es aprender a aplicar los procedimientos estadísticos y a reconocer los límites de sus conclusiones.
